# Portofolio Neina Khairani

Website portofolio pribadi Neina Khairani, siswi Rekayasa Perangkat Lunak di SMK Negeri 20 Jakarta yang tertarik pada pengembangan web, desain, dan teknologi.

## Fitur

- Halaman profil, pendidikan, keterampilan, pengalaman, dan proyek.
- Tampilan responsif untuk desktop dan perangkat seluler.
- Navigasi seluler, animasi saat menggulir, dan tombol kembali ke atas.
- Kartu proyek dengan detail dan tautan proyek.
- Tombol untuk mengunduh CV.
- Formulir kontak yang menyiapkan pesan melalui aplikasi email.

## Teknologi

- HTML
- CSS
- JavaScript

Proyek ini berupa website statis dan tidak memerlukan proses build atau instalasi dependensi.

## Menjalankan secara lokal

1. Unduh atau clone repositori ini.
2. Pastikan semua berkas proyek tetap berada di dalam folder yang sama.
3. Buka `index.html` di browser.

Untuk kemudahan saat mengedit, buka folder proyek di Visual Studio Code dan jalankan `index.html` menggunakan ekstensi Live Server.

## Struktur berkas

```text
.
├── index.html              # Halaman utama portofolio
├── style.css               # Gaya halaman utama
├── cv-neina-khairani.html  # Halaman CV
├── cv.css                  # Gaya halaman CV
├── neina-khairani.jpeg     # Foto profil
├── portfolio.png           # Gambar preview portofolio
├── nihongo.png             # Gambar preview NihongoLearn
├── majelis sayur.png       # Gambar preview Majelis Sayur
└── bank.jpeg               # Gambar preview website bank syariah
```

Jangan memindahkan gambar atau berkas CSS tanpa memperbarui alamat berkas yang digunakan di HTML dan CSS.
